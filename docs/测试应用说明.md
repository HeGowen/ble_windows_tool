# 测试应用说明（BLE Windows Tool）

## 目标

这个工具做“盒子 + 雷达 BLE 诊断”，用于回答以下问题：

1. Windows 蓝牙环境是否健康。
2. 是否能扫描到目标盒子。
3. 是否能完成 GATT 连接与通知订阅。
4. 是否持续收到盒子数据帧。
5. 是否能扫描/连接雷达并持续收到 I/Q 数据。

## 处理流程

1. 启动后先采集系统蓝牙健康信息。
2. 先执行盒子扫描并打分，选择盒子目标。
3. 连接盒子并发现固定 UUID 的 service/rx/tx。
4. 启用 notify 并发送 `sync_time/connect_all/collect_all`。
5. 持续收包并记录 frame/type 统计、分类统计和抽样值。
6. 若启用雷达，再执行雷达扫描并打分，选择雷达目标。
7. 连接雷达并发送 `sync_time/collect_switch`，记录 I/Q 统计与抽样值。

## 关键日志与字段

- `bluetooth_health.json`
  - `ServiceStates`: 蓝牙相关服务状态。
  - `RadioStates`: 蓝牙硬件开关状态。
  - `Notes.quick_scan`: 快速扫描是否能工作。

- `scan_attempts.log`
  - `score`: 候选得分（越高越可能是盒子）。
  - `heuristic`: 是否通过盒子判定。
  - `reason`: 命中的规则（地址/名称/厂商数据/service）。

- `radar_scan_attempts.log`
  - 雷达候选设备清单与打分。
  - `score/heuristic/reason` 含义同上，但规则偏向雷达。

- `packets.log`
  - `frame=0x8000`: 数据上传包。
  - `frame=0x8001`: 状态上报包。
  - `eeg/ecg/o2/audio_*`: 数据类型提示。
  - `sample[eeg/ecg/o2/audio]`: 周期抽样值日志。

- `radar_packets.log`
  - `frame=0x8000 ... radar_iq_pairs=... i0=... q0=...`
  - `sample[iq] I=[...] Q=[...]`: 周期抽样值日志。

- `summary_box.json`
  - `SessionConnected`: 成功建立会话次数。
  - `SessionDisconnected`: 会话内断开次数。
  - `TotalNotifications`: BLE 通知计数。
  - `TotalFrames`: 成功解析帧计数。
  - `FuncCounts/DataTypeCounts`: 功能码与数据类型统计。
  - `CategoryCounts`: 分类计数（eeg/ecg/o2/audio 以及状态类）。

- `summary_radar.json`
  - `MmwaveFrames`: 雷达毫米波帧计数。
  - `IqPairs`: 累计 I/Q 点对计数。

- `summary.json`
  - 本次运行总览，包含盒子和雷达摘要状态。

## 一键运行

双击 `run_ble_windows_tool.bat` 即可。
