# 测试应用说明（BLE Windows Tool）

## 目标

这个工具只做“盒子 BLE 诊断”，用于回答以下问题：

1. Windows 蓝牙环境是否健康。
2. 是否能扫描到目标盒子。
3. 是否能完成 GATT 连接与通知订阅。
4. 是否持续收到盒子数据帧。

## 处理流程

1. 启动后先采集系统蓝牙健康信息。
2. 执行多次 BLE 扫描（可配置），每次记录完整候选设备。
3. 按规则对候选设备打分并选择一个目标。
4. 尝试连接目标并发现固定 UUID 的 service/rx/tx。
5. 启用 notify 并发送 `sync_time/connect_all/collect_all`。
6. 持续收包并记录 frame/type 统计，异常时重试连接。

## 关键日志与字段

- `bluetooth_health.json`
  - `ServiceStates`: 蓝牙相关服务状态。
  - `RadioStates`: 蓝牙硬件开关状态。
  - `Notes.quick_scan`: 快速扫描是否能工作。

- `scan_attempts.log`
  - `score`: 候选得分（越高越可能是盒子）。
  - `heuristic`: 是否通过盒子判定。
  - `reason`: 命中的规则（地址/名称/厂商数据/service）。

- `packets.log`
  - `frame=0x8000`: 数据上传包。
  - `frame=0x8001`: 状态上报包。
  - `eeg/ecg/o2/audio_*`: 数据类型提示。

- `summary.json`
  - `SessionConnected`: 成功建立会话次数。
  - `SessionDisconnected`: 会话内断开次数。
  - `TotalNotifications`: BLE 通知计数。
  - `TotalFrames`: 成功解析帧计数。
  - `FuncCounts/DataTypeCounts`: 功能码与数据类型统计。

## 一键运行

双击 `run_ble_windows_tool.bat` 即可。
